# 검증 전 MES 원장과 업무 서비스를 프레임워크에서 분리한다

자재 소비, LOT 처분, 보전, 예비부품, 생산 툴, 유틸리티와 OEE의 업무 원장 및 서비스는 먼저 NexaMES의 소유 모듈에서 검증하고, NexaFramework에는 설비 프로젝트가 호출할 수 있는 작고 안정된 계약과 기술적인 실행 기반만 둔다. 설비마다 달라지는 TRACE 해석, 자재 소비량 산정, 레시피 검증과 상태 분류는 플러그인 어댑터가 담당하고, MES는 멱등성·재고 원자성·감사 이력·조회 모델을 숨기는 깊은 모듈을 제공한다. 검증되지 않은 테이블이나 MES 용어를 프레임워크에 먼저 넣으면 설비와 MES 배포 주기가 결합되고 되돌리기 어려우므로 이 순서를 유지한다.
