# 읽기경로 Restore 전수감사 백로그 (2026-06-17)

워크플로 `readpath-restore-audit` (92 에이전트, 모듈 리포지토리 44개 병렬 감사 → 발견 항목별 적대적 검증).
결과: raw 48건 → 적대적 검증 확정 34건. 배경·규칙은 메모리 [[project-readpath-restore-pattern]].

## 상태

- **DefectClass (HIGH, 수정완료 df85c32)** — 읽기경로 `Deactivate()` 결합 부수효과로 IsDeleted/DeletedAt 손상. Restore로 교체 + 회귀 3종.
- **나머지 33건 (미해결)** — 대부분 감사 메타데이터(CreatedAt/CreatedBy/UpdatedAt/UpdatedBy) 미복원의 체계적 패턴. 비즈니스 상태는 Create+뮤테이터로 정상 복원되는 경우가 많음(코드 정독 재검증 권장). 올바른 수정은 `AuditableEntity.RestoreAudit(...)` 기반 + Row audit 컬럼 매핑 + Restore 시그니처 확장 — 다수 시그니처 변경의 대형 작업이라 설계 결정 필요.
