# Frontend Coexistence Architecture

## 개요

NAF Studio는 Low-Code 플랫폼과 일반 프론트엔드 개발 환경이 공존할 수 있도록 설계한다.

...

# 최종 목표

## Low-Code

현업도 개발 가능

## Pro-Code

React/Vue 개발자도 자유롭게 개발 가능

## Platform

모든 화면이 동일 Runtime 위에서 동작

모든 데이터 접근이 Query Engine을 통과

모든 이벤트가 Event Bus를 통과

모든 권한이 Security Engine을 통과

단일 플랫폼으로 통합 운영 가능
